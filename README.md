# OrderFlow-ZIO

Микросервис по обработке заказов, написанный на Scala 3 с использованием функционального эффект-стека ZIO. 

Смысл: сервис принимает корзину от клиента, валидирует её, проверяет наличие товаров на складе, пересчитывает актуальную стоимость по каталогу, проводит оплату и сохраняет заказ в БД. Взаимодействие с внешними системами построено по паттерну **Saga** (с компенсацией при сбоях) и **Best-Effort** (события в Kafka не блокируют основной процесс).

## Возможности
* **Stateless HTTP API** — легковесный REST-сервер на базе ZIO HTTP.
* **Saga Pattern** — при сбое сохранения в БД после успешной оплаты автоматически вызывается `refund`.
* **Защита от подмены цен** — итоговая сумма рассчитывается по данным каталога, а не по тем, что прислал клиент.
* **Строгая типизация ошибок** — `sealed trait OrderError` с маппингом в корректные HTTP-статусы.
* **Best-Effort интеграции** — если Kafka недоступна, заказ всё равно создаётся (ошибка логируется).
* **ZLayer DI** — внедрение зависимостей на уровне типов, легко подменять базы данных и клиенты на моки.

## Технологии
Scala 3, ZIO, ZIO HTTP, ZIO JSON
